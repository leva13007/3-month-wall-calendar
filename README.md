# 3-month wall calendar

A small React + TypeScript app: a 3-month wall calendar (current month + next 2), like a paper calendar on the wall.
I need it for personal use because I can't get a physical Ukrainian calendar anymore, and paper cells are too small for several events per day.

## Features
- 3 stacked months (current + next 2), weeks start on Monday, ISO week numbers
- Several events per day; a day with events shows a border and a counter
- Click a day to add, view, edit or delete events
- Previous / next month and a "Today" button
- Export / import events as a JSON file
- Installable as a PWA, sized for a vertical monitor
